#  Expense Tracker

A lightweight Expense Tracker built with **React**, **Tailwind CSS**, and **Vite**. Persists all spending data locally in `localStorage`.

##  Features
-  **Dashboard Stats**: Total Spent, Highest Expense & Total Count.
-  **Category Pie Chart**: Interactive SVG visual chart for expenses.
-  **CRUD Operations**: Add, Edit, and Delete expenses.
-  **Search & Filters**: Filter by category and sort by date or amount.
-  **Local Storage**: Automatically saves data in the browser.

##  Tech Stack
- React 19 + Vite
- Tailwind CSS v4
- Lucide React (Icons)
- Browser LocalStorage

##  Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Start local server
npm run dev

# 3. Build for production
npm run build
